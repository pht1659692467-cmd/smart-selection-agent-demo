# Selection Lab · 智能选品产品 Demo

面向B2B销售的选品工作流演示：客户绑定与画像、P0缺项追问、单品/套装方案、预算分配、方案内套装切换、换款、收藏、Excel/PPT导出及经营看板。

这是前端规则模拟与产品交互原型，使用虚构数据；尚未接入真实LLM、Agent工具调用、CRM、价格或库存API。候选池规则模拟AI预算分配，页面会标明来源。刷新重置会话，前端管理员入口是演示视图，不是认证系统。

## 演示

预期演示地址：https://pht1659692467-cmd.github.io/smart-selection-agent-demo/ （尚未完成发布，部署成功后确认）。

仓库地址：https://github.com/pht1659692467-cmd/smart-selection-agent-demo 。网页是供面试官直接操作的链接；本仓库是代码与产品说明链接。

1. 客户画像→绑定客户→选择“示例客户A”。
2. 复制下面任一段到新会话。
3. 查看方案→套装→商品的层级，切方案分别显示不同数量的合格套装。
4. 收藏/导出整个方案。Excel每套一个工作表，PPT按套装分段，不把备选金额相加。

### 各品独立预算

    运动鞋300双，外套300件，鞋每双450元，外套每件300元，男女各半，品牌不限，请生成方案

### 整单预算

    运动鞋300双，外套300件，整单总预算22.5万元，男女各半，品牌不限，请生成方案

也支持每套750元；只说“总预算750元”会先确认整单还是每套。数量不等时每套配比需澄清。

## 本地运行与检查

需要Node.js，无第三方npm依赖：

    npm test
    npm start

打开 http://127.0.0.1:4192 。现有53条回归检查覆盖P0、预算、方案/套装层级、状态隔离、耗时口径及页面基线。文件结构校验与浏览器测试范围见本地原项目记录；不得把规则原型描述为已上线的生产Agent。
